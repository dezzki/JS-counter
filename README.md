# People Counter

A simple JavaScript counter app that tracks the number of people entered.

## Features

- **Increment** – add 1 to the current count
- **Save** – record the current count and add it to the total
- **Reset** – clear all entries and totals

## Usage

Open `index.html` in a browser. No build step or dependencies required.

## Files

- `index.html` – markup
- `styles.css` – styling
- `index.js` – app logic
- `practice.js` – standalone JS practice snippets
